Для запуска веб-приложения необходимо написать npm start в консоли и корневой папке ИЛИ запустить bat файл start.bat

Структура проекта
Server.js основной файл. Организует соденинение с базой данных, а также маршруты всех запросов от Пользователя.
Папка public содержит все ресурсы и элементы проекта (html, css и js-файлы)
Папка Enteringpage ->  функционал страницы входа.
Папка Administrator -> функционал Администратора приложения.
Папка User ->  функционал Пользователя приложения.
Папка Projectresources -> Изображения и иконки, используемые в приложении.

Весь код реализован на callback-методах.
